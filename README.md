# ☕ Sheffield Café Website

A responsive café website built as part of my web development learning journey.

The project represents a fictional local café in Sheffield and focuses on creating a clean, user-friendly website using HTML, CSS and JavaScript.

## 🌐 Live Website

[Visit Sheffield Café Website](https://priyankam-tech.github.io/sheffield-cafe-website/)

## ✨ Features

- Responsive café website design
- Navigation between website sections
- Café menu cards
- Food and drink images
- Interactive "Show More Menu" feature
- Interactive contact button
- Email contact link
- Google Maps location link
- Mobile-friendly layout
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
